# v0.29.0 — Plan

**Theme:** account history & retrospective view, plus three broken date/price
dialogs surfaced by user testing.

**Branch model:** single shared branch `feat/v0.29.0`. One task per commit
(mono-commit) or a small commit series per task (multi-commit). Reviewers and
coverage run after each task; the branch is pushed task-by-task so every CI job
is verified green before the next task starts. Review fixes fold into the
task's mono-commit (amend) or land as an extra commit on a multi-commit task.
Batch-merge at release — no per-task merges to `main`.

**Commit bookends:**

- **First commit** (`docs:`) — this plan + the `docs/todo.md` rewrite listing
  all tasks.
- **Last commit** (`chore:`/`docs:`) — housekeeping: delete this plan doc and
  prune every resolved `docs/todo.md` / `docs/techdebt.md` entry.

**Model:** opus throughout (per user direction).

## Tasks

### Features (Workflow A — spec → contract → plan → impl)

**T1 — As-of-date view on Account Details** (#1)

- BE: `get_holding_snapshot_as_of` returns a single holding snapshot. A full
  retrospective view needs all holdings + cash as of a date → new use-case
  command `get_account_holdings_as_of(account_id, iso_date)` reusing
  `account_performance` valuation/FX helpers. Spec + contract.
- FE: date selector on `AccountDetailsView.tsx`, threaded through
  `useAccountDetails.ts` / `accountDetailsGateway`; "viewing past date" banner;
  default = today.
- Est: ~400–600 LOC churn.

**T2 — Historical account-value chart** (#2)

- BE: value-over-time series reusing `account_performance/orchestrator.rs`
  (`period_end_dates`, `load_priced_assets`, `load_rate_map`). New command
  `get_account_value_series(account_id)` or performance use-case extension.
- FE: charting-library decision (recharts for speed, or lightweight-charts /
  uPlot for bundle size — decide at design time); chart component on the
  performance page.
- Est: ~500–700 LOC churn + one new dependency.
- Shares the as-of-date valuation core with T1 — sequence together.

### Bug fixes (Workflow B)

**T3 — Price modal asset selector feels readonly** (#3) — FE

- `src/ui/components/field/ComboboxField.tsx` + `useComboboxField.ts`: open the
  dropdown on focus/click (not only at `query.length >= 2`), add a dropdown
  affordance. Shared component — verify other consumers (asset/category
  pickers). Est: ~40–70 LOC.

**T4 — Price date never persisted** (#4) — FE

- `usePriceModal.ts` `record()`: call `setLastOperationDate(accountId, date)`
  on success, mirroring the other seven operation hooks. Est: ~5 LOC + test.

**T5 — Cash add/remove ignores stored date** (#5) — FE

- `useDepositTransaction.ts` / `useWithdrawalTransaction.ts`: fix the once-only
  initializer so the date re-seeds when `accountId` resolves; verify writeback.
  Est: ~30–50 LOC + tests.

### Backlog pick
