# v0.30.0 — Plan

**Theme:** fold the as-of-date view into the live account screen, drop the
unreliable date-scoped price fetch, and add a real per-year total-return yield.

**Branch model:** single shared branch `feat/v0.30.0`, one commit (or small
series) per task, reviewers + coverage + visual-proof after each, pushed
task-by-task against a draft PR for per-push CI. Batch-merge at release.

**Commit bookends:** first `docs:` commit = this plan + todo entries; last
`chore:` commit = delete this plan + prune shipped todos.

**Order:** T2 (cleanup, shrinks the header) → T1 (rework the header + as-of) →
T3 (perf yield) → T5 (`period_end_dates` dedup, same file as T3) → T6 (B18
extraction, cleanest after T1 removes a consumer) → T4 (`DateField` fix, FE,
independent). T1 and T2 both touch `AccountDetailsView.tsx`; doing the removal
first keeps T1's rework clean. T3/T5/T6 are grouped in the `account_performance`
area.

Plus 3 area-aligned techdebt items (T4–T6, below).

**Decisions (proceeding with these):**

- **T1 as-of mode is read-only.** When a past date is selected, the page hides/
  disables every mutation (price-refresh, the Add/Record menu + FAB, and the
  row buy/sell/deposit/withdraw/dividend/free-shares actions) and shows a
  "viewing as of … — back to today" banner. Recording against a historical
  snapshot is ambiguous. Default = today (no banner, fully live).
- **T3 year yield = total return, modified Dietz.** Numerator = period price
  P&L (realized + unrealized) **+ dividends**; denominator = `previous_value` +
  time-weighted external flows (`cash_flow` + `asset_flow`); dividends are
  **not** treated as an external flow (they are part of the return). This
  differs from the existing `period_over_period` (price-only Dietz), so it is a
  **new** metric, not a change to the existing one.

## T1 — As-of-date in the live account-details view (feature)

- **BE:** add `as_of_date: Option<String>` to `get_account_details` (api +
  orchestrator). `None` → today (unchanged). `Some(date)` → compute the full
  `AccountDetailsResponse` as of the date:
  - holdings: replay per-asset qty+VWAP via `Account::holding_snapshot_as_of`;
    cash via `cash_balance_as_of`; active = qty>0 at the date.
  - prices: latest on-or-before the date (per-asset `get_asset_prices` +
    carry-forward, computed **inside** account_details — avoid importing
    `account_performance::load_priced_assets` so as not to extend the B18 debt).
  - FX: `resolve_rate(..., as_of_date)`; realized_pnl + dividends filtered to
    transactions ≤ date; closed_holdings = assets with txns ≤ date but qty 0.
  - validate ISO + reject future date.
  - **Remove** the v0.29.0 `account_holdings_as_of` use_case + command (folded in).
- **FE:** date selector in `AccountDetailsView` header (default today, shared
  `DateField`), threaded `useAccountDetailsView` → `useAccountDetails` →
  `gateway.getAccountDetails(accountId, asOf)`. As-of banner + "back to today";
  disable/hide mutations (per the decision above). **Remove** the
  `holdings_as_of/` sub-feature (modal/hook/presenter/tests) + its header button
  - `asOfOpen` wiring.
- Est: ~400–600 LOC churn (incl. the removals). Spec note for the as-of rules; visual-proof the as-of view (live + past-date).

## T3 — Per-year total-return yield on the performance page (feature)

- **BE:** add `year_yield: Option<PerformanceMetric>` to `PerformancePeriod`

- Est: ~150–250 LOC + tests. Visual-proof the performance table with the new column.
